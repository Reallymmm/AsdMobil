# Как запустить LUCID ✦

Инструкция разделена на два независимых пути:
**[Веб-версия](#веб-версия)** и **[телефон (iOS / Android)](#телефон-ios--android-через-expo-go)**.

---

## 0. Подготовка (общая, один раз)

Нужны:

- **Node.js 20+** (рекомендую LTS 22) — проверить: `node -v`
- **Git** (не обязателен — можно скачать ZIP, см. ниже)
- для телефона — приложение **Expo Go** (бесплатно, из App Store / Google Play)

### Если Node.js ещё не установлен

| ОС | Как поставить |
|---|---|
| **Windows** | Зайдите на [nodejs.org](https://nodejs.org) → большая зелёная кнопка **«Download Node.js (LTS)»** → запустите `.msi` → далее-далее-готово. **Важно: закройте и заново откройте терминал** (или перезагрузите ПК), иначе `node` не будет найден. |
| **macOS** | Там же скачайте `.pkg`, либо `brew install node` (если есть Homebrew). |
| **Linux** | `sudo apt install nodejs npm` или через [nvm](https://github.com/nvm-sh/nvm). |

Проверка после установки (в новом терминале):

```bash
node -v    # должно быть v22.x (или v20+)
npm -v     # 10.x
```

> Если Windows пишет «node не является внутренней или внешней командой» —
> терминал открыт со старыми настройками: закройте его и откройте заново.

### Получить проект

С Git:

```bash
git clone -b arena/01a0a72f-asdmobil https://github.com/Reallymmm/AsdMobil.git
cd AsdMobil
```

Без Git: на странице репозитория GitHub выберите в выпадающем списке веток
**`arena/01a0a72f-asdmobil`** (не main!) → зелёная кнопка **Code → Download ZIP**
→ распакуйте → откройте терминал в распакованной папке.

Затем — зависимости:

```bash
npm install
```

> **Проверка, что всё ставится:** ветка `arena/01a0a72f-asdmobil` собирается
> и запускается (веб-дев: ~1000 модулей; продакшен: `npx expo export`).

## Веб-версия

### Вариант A — дев-режим (с live-reload)

Удобно во время разработки: сохраняете файл — страница обновляется сама.

```bash
npm run web
```

- Expo сам откроет браузер на **http://localhost:8081** (если не открыл — зайдите вручную).
- Первый запуск собирает бандл ~15–60 с (внизу страницы виден прогресс).
- Остановить: `Ctrl+C` в терминале.

> Если в консоли браузера появилась ошибка загрузки `canvaskit.wasm`
> (файл потерялся из `public/`), восстановите его:
> ```bash
> cp node_modules/canvaskit-wasm/bin/full/canvaskit.wasm public/
> ```

### Вариант B — продакшен-сборка (быстрая, как «настоящий сайт»)

```bash
# 1. собрать статику в dist/
npx expo export --platform web

# 2. поднять локальный сервер (из репозитория)
node tools/serve.mjs 8080 dist
```

Открыть **http://localhost:8080**.

Каталог `dist/` самодостаточен — его можно залить на любой статический
хостинг (nginx, GitHub Pages, Netlify, Vercel): просто скопируйте содержимое
`dist/` в корень сайта.

### Открыть веб-версию на телефоне (без Expo Go)

1. Узнайте IP компьютера в локальной сети:
   - macOS/Linux: `ipconfig getifaddr en0` или `hostname -I`
   - Windows: `ipconfig` → «IPv4-адрес»
2. Запустите сервер: `node tools/serve.mjs 8080 dist`
3. На телефоне (в том же Wi-Fi) откройте `http://<IP-компьютера>:8080`

> В веб-версии нет виброотклика (это ограничение браузеров) и
> мультитач ограничен возможностями тачскрина/тачпада.

## Телефон (iOS / Android) через Expo Go

Самый быстрый путь — ничего не нужно компилировать в Xcode/Android Studio.

**Шаг 1.** Установите **Expo Go**:
- iPhone — App Store
- Android — Google Play

**Шаг 2.** Запустите дев-сервер на компьютере:

```bash
npx expo start
```

В терминале появится **QR-код**.

**Шаг 3.** Отсканируйте QR-код:
- **Android:** откройте Expo Go → *Scan QR code* → наведите на код;
- **iPhone:** отсканируйте **Камерой** (обычным приложением камеры) →
  нажмите на появившийся баннер.

**Шаг 4.** Подождите первую загрузку бандла (30–60 с), пока экран не
зальётся «жидким» градиентом.

Готово: выберите теги на экране «Призма» → «Соткать сон» → проведите
пальцем по жидкости (можно несколькими пальцами — до 4 вихрей одновременно).

Полезное в терминале, где запущен `expo start`:
- `w` — открыть веб-версию, `a` — Android, `i` — iOS-симулятор;
- `Ctrl+C` — остановить.

### Если телефон не подключается

| Проблема | Решение |
|---|---|
| Телефон и компьютер в разных сетях | Подключите оба к одной Wi-Fi сети |
| Корпоративный Wi-Fi изолирует устройства | Запустите `npx expo start --tunnel` (VPN-туннель через Expo; нужен интернет) |
| Брандмауэр Windows блокирует порт | Разрешите Node.js входящие на порт 8081 |
| Expo Go очень старый | Обновите Expo Go (проект — Expo SDK 57) |
| Ошибка «canvaskit.wasm 404» в вебе | `cp node_modules/canvaskit-wasm/bin/full/canvaskit.wasm public/` |

### Что проверить именно на телефоне

- **Виброотклик** при выборе тегов, нажатии кнопок и касании жидкости —
  в вебе его нет;
- **многопальцевые вихри** в визуализаторе;
- плавность пружинных переходов (60 fps на современных устройствах).

## Продвинутый вариант: сборка APK / IPA (EAS Build)

Нужна, если хотите установить приложение как «настоящее», без Expo Go.

```bash
# войти в Expo-аккаунт (создать: https://expo.dev)
npx eas-cli login

# APK для Android — ставится напрямую на телефон
npx eas-cli build -p android --profile preview
```

- **Android:** в профиле `preview` (`eas.json` в репозитории) собирается APK —
  скачайте по ссылке из терминала и откройте на телефоне.
- **iOS:** сборка на реальное устройство требует аккаунт Apple Developer
  (платный). Для теста в симуляторе: `eas build -p ios --profile preview`
  (соберётся под симулятор, запуск на Mac в Xcode).

> Все зависимости проекта (Skia, Reanimated, Haptics, AsyncStorage)
> совместимы с Expo Go, поэтому для повседневной отладки EAS не нужен.

## Краткая шпаргалка

```bash
npm run web                          # веб, дев-режим → localhost:8081
npx expo export --platform web       # веб, продакшен → dist/
node tools/serve.mjs 8080 dist       #   …и сервер к нему → localhost:8080
npx expo start                       # телефон: QR-код → Expo Go
npx expo start --tunnel              #   …если Wi-Fi не пускает
node tools/shader-preview.mjs        # оффлайн-рендер шейдеров в PNG
node tools/generate-assets.mjs       # перегенерация иконок приложения
```
