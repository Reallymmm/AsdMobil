# LUCID — дневник снов ✦

Мобильное приложение-дневник снов в эстетике **Liquid Glassmorphism**:
матовое стекло, «жидкий» анимированный фон и **генеративное искусство** —
каждый сон визуально соткан из выбранных тегов локальными GPU-шейдерами,
без единого обращения к внешним API нейросетей.

<p align="center">
<i>Призма → Жидкий сон → Музей снов</i>
</p>

---

## Экраны

| Экран | Название | Что происходит |
|---|---|---|
| 1 | **Призма** | Запись сна. Парящая стеклянная сфера (шейдер с «преломлением», френелем и бликом), поле названия, облако тегов-«пилюль» и пульсирующая кнопка «Соткать сон». Выбор тега мгновенно перекрашивает сферу — палитра «перетекает». |
| 2 | **Жидкий сон** | Полноэкранный интерактивный визуализатор. Касания пальцев рождают волны и завихрения жидкости. Оверлей «запотевшего стекла»: название и дата сна. |
| 3 | **Музей снов** | Галерея сохранённых снов. Каждая карточка — матовое стекло, сквозь которое просвечивает уникальный градиент данного сна (цвета + наклон градиента выводятся из сида записи). Фон музея «дышит» смесью всех снов. |

## Генеративный движок: «Теги → Параметры»

18 тегов трёх категорий. Каждый тег — это не метка, а **визуальный профиль**:

| Тег | Палитра (deep → mid → accent) | Скорость | Турбулентность | Звёзды |
|---|---|---|---|---|
| 🔥 Огонь | угольно-чёрный → алый → оранжевый неон | 1.25 | 1.30 | 0.55 |
| 💧 Вода | морская тьма → глубокий синий → циан | 0.60 | 0.75 | 0.45 |
| 🌬️ Воздух | ночное небо → сталь → ледяное свечение | 1.50 | 1.80 | 0.60 |
| 🪨 Земля | тёмная почва → охра → тёплое золото | 0.35 | 0.50 | 0.30 |
| ✨ Радость | тёплая ночь → янтарь → золотое сияние | 1.10 | 0.85 | 0.85 |
| 👁️ Страх | чёрная тень → фиолетовая мгла → кислотный неон | 1.45 | 1.55 | 0.50 |
| 🌙 Покой | бирюзовая глубина → морская волна → аквамарин | **0.25** | **0.45** | 0.40 |
| 🌧️ Грусть | сумрак → стальной синий → пыльно-голубой | 0.45 | 0.55 | 0.35 |
| 🌈 Эйфория | ночная сирень → пурпур → розовый неон | 1.60 | 1.05 | 0.90 |
| 💀 Кошмар | чёрный → кровавый → багровый | **2.30** | **2.00** | 0.45 |
| 🌌 Космос | пустота → индиго → фиалковое свечение | 0.30 | 0.50 | **1.00** |
| 🌲 Лес | чаща → мох → изумрудный неон | 0.40 | 0.65 | 0.50 |
| 🏙️ Город | асфальт → сталь → неоновый циан | 0.90 | 1.00 | 0.70 |
| 🌊 Океан | бездна → глубина → бирюзовая пена | 0.55 | 0.80 | 0.45 |
| ⛈️ Шторм | тьма → грозовой сланец → электрический белый | 1.85 | 1.75 | 0.55 |
| 🌅 Рассвет | предрассветный → розовый коралл → персик | 0.50 | 0.55 | 0.50 |
| 🏔️ Горы | ночь → сине-серый → ледниковая белизна | 0.35 | 0.45 | 0.40 |
| 🌆 Сумерки | индиго-ночь → пурпур → пыльная орхидея | 0.45 | 0.55 | 0.45 |

**Правила смешивания** (`src/core/dreamEngine.ts`):
- палитры усредняются с весами (акцент — 1.35, он задаёт «неон» сна);
- скорость/турбулентность растут с числом тегов — сон «плотнеет»;
- звёздная пыль — по максимуму среди тегов;
- **сид записи** (хэш id) слегка поворачивает оттенок (±6% круга) и
  джиттерит параметры → два сна с одинаковыми тегами выглядят по-разному;
- всё детерминированно и считается на устройстве.

## Шейдеры (SkSL, Skia Runtime Effects)

Все эффекты — фрагментные шейдеры на **SkSL** через
`@shopify/react-native-skia` (Metal на iOS, OpenGL/Vulkan на Android,
WebGL/CanvasKit в браузере — один и тот же код везде).

| Файл | Что делает |
|---|---|
| `src/core/shaders/noise.ts` | sin-hash → value noise → fbm (5 октав) |
| `src/core/shaders/liquid.ts` | «жидкий градиент»: domain warping `fbm(p + w·fbm(p + w·fbm(p)))`, виньетка, зерно |
| `src/core/shaders/sphere.ts` | стеклянная сфера: нормаль сферы, изгиб выборки у края («линза»), френелевский ободок, specular-блик, гало |
| `src/core/shaders/visualizer.ts` | интерактивная жидкость: до 4 касаний (вихрь-закрутка + расходящиеся кольца + свечение), «звёздная пыль» по `u_particles`, виньетка «запотевшего стекла» |

Проверить шейдеры без запуска приложения можно скриптом
`tools/shader-preview.mjs` (рендерит PNG-кадры через Node + CanvasKit).

## Стек

- **Expo SDK 57**, React Native 0.86, TypeScript
- **@shopify/react-native-skia** — шейдеры и Canvas
- **react-native-reanimated** — пружинные анимации (все переходы «мягкие и текучие»), worklet-анимация юниформов шейдеров на UI-потоке
- **AsyncStorage** — локальное хранение снов (UserDefaults/SQLite под капотом)
- **expo-haptics** — виброотклик на тегах, кнопках и касаниях жидкости
- **expo-linear-gradient** — градиенты карточек музея
- Шрифты: **Unbounded** (заголовки) + **Manrope** (текст), обе с кириллицей

## Запуск

Подробная пошаговая инструкция (веб и телефон по отдельности): **[RUN.md](./RUN.md)**.

```bash
npm install

# веб-версия, дев-режим (live-reload)
npm run web

# веб-версия, продакшен: статика в dist/
npx expo export --platform web
node tools/serve.mjs 8080 dist

# телефон (iOS/Android) через Expo Go — QR-код в терминале
npx expo start
```

> `public/canvaskit.wasm` нужен для веба — он уже лежит в репозитории;
> восстановить: `cp node_modules/canvaskit-wasm/bin/full/canvaskit.wasm public/`

## Соответствие ТЗ (Шаги 1–6)

1. **Тема с «жидким» фоном** — `theme.ts` + `shaders/liquid.ts`, фон живёт на всех экранах и реагирует на сны.
2. **«Стеклянный контейнер»** — `GlassContainer` (blur + граница + тень; на вебе — настоящий `backdrop-filter`).
3. **Логика «теги → параметры»** — `core/tags.ts` + `core/dreamEngine.ts` (палитры, скорость, турбулентность, плотность частиц, сид-уникальность).
4. **Экран записи с интерактивной сферой** — `RecordCanvas` (шейдер призмы) + `RecordScreen`; сфера перекрашивается в реальном времени.
5. **Локальное хранение** — `core/storage.ts` (AsyncStorage, ключ `lucid.dreams.v1`).
6. **Финальные штрихи** — пружинные переходы экранов (`AppNavigator`), пружины на всех нажатиях, хаптики, «дыхание» музея. Звук оставлен опциональным расширением (осознанно не включали, чтобы не тянуть ассеты).
